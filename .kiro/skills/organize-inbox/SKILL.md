# Organize Inbox

For each Markdown file in `Inbox/`:

1. Preserve the original note.
2. Identify its purpose: reference, meeting, task, certification note, work note, article idea, or personal note.
3. Propose:
   - improved title;
   - destination folder;
   - minimal tags and frontmatter;
   - related wikilinks;
   - extracted tasks;
   - whether it could support a Builder Center or DEV article.
4. Write the proposal to `Proposals/` with the original path and proposed diff.
5. Flag uncertainty and sensitive information.
6. Do not apply the proposal until the user names that proposal and explicitly approves it.
7. Before applying, back up every changed source file and request final confirmation after showing the diff.
