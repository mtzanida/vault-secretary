# Community Builder meeting prep

1. Read `.vault-secretary/cache/calendar-events.json` and select upcoming events marked `community_builder: true`.
2. Display times in `Europe/Athens` and include configured reminders.
3. Search the vault for related Community Builder, Serverless, AWS, article, and event notes.
4. Create a private pack in `Briefings/` with context, related wikilinks, three preparation tasks, questions, and a follow-up checklist.
5. Mention whether a meeting link exists, but never copy private URLs, attendees, or descriptions into public drafts.
6. Do not edit the calendar or source notes.
